## 1. Overview
This Privacy Policy outlines how **ChittorTech** collects, uses, protects, and discloses information for the **गढ़सेवा : Chittorgarh-Parishad** mobile application developed for Nagar Parishad Chittorgarh, Rajasthan.

## 2. Information Collected
- **Administrative Credentials:** Official municipal email, assigned role, and secure authentication tokens.
- **Citizen Grievance Data:** Complainant name, mobile number, ward number, grievance description, category, and landmark.
- **Verification Records:** Two-step resolution confirmation notes, citizen satisfaction ratings, and timestamps.
- **Device & Network Parameters:** Basic device OS version and connectivity state for database synchronization.

## 3. Permissions Used
- `POST_NOTIFICATIONS`: Real-time alerts for municipal grievance updates and escalations.
- `INTERNET`: Secure HTTPS/TLS communication with Supabase backend.
- `DIAL_INTENT`: Direct launcher for standard device phone dialer (no automated calling or call recording).

## 4. Data Security & Sharing
- **Zero Commercial Sharing:** We do not sell, rent, or monetize user data with third-party advertisers.
- **Encryption:** All API calls are secured via TLS 1.3 / HTTPS.
- **Data Access:** Restricted solely to authorized municipal personnel of Nagar Parishad Chittorgarh.
